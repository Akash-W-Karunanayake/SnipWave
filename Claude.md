# CONTEXT
An application that has the capability to multicut an audio file in a single run and then create a zip file of the cut peices of that audio file. Basically, I want an app that cut long audio in to short parts and then zip them.

# IMPORTANT

You have the total freedom to design the application as you want. You can use any technology that you think is suitable for this application. Brainstorm and provide the best possible solution for this application with the best possible UI & UX design. 

# TASK LIST

1. Create a application that run on the local machine which has capablity of performing the following tasks:
    - Upload a specific audio file to the workspace. 
    - The audio file must be playeble within the application. 
    - The application must have a slider to cut the audio file in to short parts. The buttons must be there to play/ stop and change the position of the slider for 0.1 second interval. In seekbar, the position of the slider must be displayed in seconds. Also over all length of the audio file must be displayed in seconds. 
    - User must be able to select the multicut positions and then split them. In the end, after user confirm that the splitting is done correctly, the application must create a zip file of the cut peices of that audio file.


2. UI Design
    - The UI must be simple and easy to use.
    - The UI must be responsive.
    - The UI must be modern and sleek.

3. Stack 
    - The stack must be something suitable for a local application. It should be able to make this application run on the local machine after installing via an exe file. 

4. Create the README file for the application that suitable for github repository.
